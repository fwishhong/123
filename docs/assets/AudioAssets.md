## 角色语音

### 是否需要语音？

**完全语音**: 成本极高，不推荐（预算$50,000+）
**部分语音**: 推荐（预算$5,000-15,000）
**无语音**: 最经济（预算$0）

### 推荐方案：部分语音

只为关键时刻配音，降低成本但保留沉浸感。

---

### 规格要求

| 属性 | 规格 |
|------|------|
| **格式** | OGG Vorbis |
| **比特率** | 96kbps |
| **采样率** | 44.1kHz |
| **声道** | Mono |
| **语言** | 英语 + 中文（双语配音） |
| **命名规范** | `voice_[char_id]_[emotion]_[number].ogg` |

---

### 语音内容（部分语音方案）

#### 1. 战斗语音（每角色20句）

**主角 + 8个可攻略角色 = 9人**

每人需要:
- 攻击音 (5种): "嘿！" "接招！" "看招！" 等
- 受伤音 (3种): "啊！" "呜..." "可恶..."
- 技能台词 (5种): 技能名称或台词
- 胜利 (2种): "我们赢了！" "做得好！"
- 失败 (2种): "怎么会..." "对不起..."
- 倒地 (1种): "啊啊啊！"
- 队友支援 (2种): "交给我！" "让我来！"

**每人20句 × 9人 = 180句**

## 技术规范

### 音频中间件

**推荐**: Unity的原生音频系统（免费）

**可选升级**:
- **FMOD** - 更专业，免费版有限制
- **Wwise** - 行业标准，免费版有限制

---

### 文件格式

| 用途 | 格式 | 说明 |
|------|------|------|
| **BGM** | OGG Vorbis | 循环音乐，压缩比好 |
| **短音效** | WAV | 低延迟，适合UI |
| **长音效** | OGG | 压缩，适合环境音 |
| **语音** | OGG | 压缩，数量多 |
| **源文件** | WAV/AIFF | 无损，用于制作 |

---

### 导出设置

#### BGM导出
```
格式: OGG Vorbis
比特率: 192kbps (高质量), 128kbps (标准), 96kbps (低质量)
采样率: 44.1kHz
声道: Stereo
循环点: 设置Loop Start/End
归一化: -1.0dB (避免削波)
淡入淡出: 0.5s (防止爆音)
```

#### SFX导出
```
格式: WAV (UI短音), OGG (环境长音)
比特率: 96kbps (OGG)
采样率: 44.1kHz
声道: Mono (大部分), Stereo (环境音)
归一化: -3.0dB
```

#### 语音导出
```
格式: OGG Vorbis
比特率: 96kbps
采样率: 44.1kHz
声道: Mono
降噪: 适度降噪
压缩器: 使EQ平衡
```

### 音量平衡

| 类型 | 相对音量 | dB |
|------|---------|-----|
| BGM | 100% | 0dB |
| SFX | 80-120% | -2 to +2dB |
| 语音 | 110% | +1dB |
| 环境音 | 40-60% | -6 to -4dB |

**动态混音**:
- 对话时: BGM降低30%
- 战斗时: SFX优先
- 环境音: 始终在背景
