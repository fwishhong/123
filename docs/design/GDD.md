## 游戏概览

### 基本信息

| 项目 | 内容 |
|------|------|
| **游戏名称** | MindLink - 认知空间 (Cognitive Space) |
| **类型** | 时间管理 RPG + 视觉小说 + 回合制战斗 + 解谜 |
| **平台** | iOS / Android |
| **开发引擎** | Unity |
| **美术风格** | 2D像素风 + 高清立绘 |
| **目标时长** | 单周目 8-12 小时，全结局 30-40 小时 |
| **语言支持** | 英语、简体中文（首发），后续支持日语、韩语 |

### 电梯推介 (Elevator Pitch)

> "在距离全球意识统合计划启动还有100天的时候，你发现了进入他人'认知空间'的能力。白天，你是个普通学生；夜晚，你要拯救那些认知崩溃的受害者。每个选择都很重要，因为你无法拯救所有人——你会选择拯救谁？又会放弃谁？"

### 核心卖点 (USP)

1. **有意义的选择** - 时间有限，无法完成所有事情，每个决定都有代价
2. **情感投资** - 8个深度角色，每个都有自己的秘密和成长弧线
3. **多层叙事** - 表面是日常校园生活，深层是科幻悬疑阴谋
4. **高重玩价值** - 15+ 结局，多周目解锁真相
5. **移动端优化** - 专为碎片化时间设计，支持随时存档

## 核心理念

### 设计支柱 (Design Pillars)

#### 1. 选择的重量 (Weight of Choice)
- 玩家永远没有足够的时间做所有事
- 每个选择都有明确的机会成本
- 没有"完美路线"，只有"你的路线"

**设计实现**:
- 100天固定时长，每天3个时间段
- 300个时间段 vs 500+ 可选活动
- 大任务有截止日期，错过即失败

#### 2. 人与人的连接 (Human Connection)
- 角色不是"工具"，而是有自己生活的个体
- 好感度不仅影响结局，也影响角色自身的命运
- 忽略某个角色可能导致他们的悲剧结局

**设计实现**:
- 每个角色有独立的危机事件
- 好感度低的角色可能在主线中"死亡"
- 角色间有复杂的关系网

#### 3. 真相的代价 (Price of Truth)
- 一周目只能看到故事的表象
- 真相分散在不同角色线和选择中
- 真结局需要综合多次游玩的信息

**设计实现**:
- 隐藏的"回忆碎片"系统
- 新游戏+ 解锁额外对话选项
- 需要特定条件组合才能触发真相路线

## 游戏机制

### 核心循环 (Core Loop)

```
日常阶段:
┌─────────────────────────────────────┐
│ 1. 查看日历和任务截止日期            │
│ 2. 选择时间段活动（早/午/晚）         │
│ 3. 执行活动（提升属性/好感度/剧情）   │
│ 4. 触发随机事件                      │
│ 5. 日终总结                          │
└─────────────────────────────────────┘
         ↓
大任务阶段:
┌─────────────────────────────────────┐
│ 1. 进入目标的"认知空间"              │
│ 2. 探索（解谜、收集线索）             │
│ 3. 战斗（应对认知防御机制）           │
│ 4. BOSS战（核心心结）                │
│ 5. 解决认知崩溃，获得奖励             │
└─────────────────────────────────────┘
         ↓
    [循环继续]
```

### 系统概览

#### 时间管理系统
- **100天时间线**: Day 1 → Day 100
- **每日3时段**: 早晨 (Morning) / 下午 (Afternoon) / 夜晚 (Night)
- **特殊日期**: 周末、节假日、剧情锁定日
- **倒计时压力**: 大任务截止日显眼提示

#### 属性系统
玩家有4项主要属性：

| 属性 | 影响 | 提升方式 |
|------|------|----------|
| **知识** (Knowledge) | 解锁高级对话选项、解谜提示 | 图书馆学习、参加讲座 |
| **勇气** (Courage) | 尝试危险选项、面对强敌 | 冒险活动、挑战困难 |
| **魅力** (Charm) | 社交成功率、特殊角色互动 | 社交活动、时尚打扮 |
| **战斗力** (Combat) | 战斗伤害和生存能力 | 训练、实战、装备 |

**属性等级**: 1-10 级，每级需要递增的经验值
**隐藏阈值**: 某些事件需要属性达到特定等级才能触发

#### 好感度系统
- **8个主要角色**，每个好感度 0-10 级
- **好感度作用**:
  - Lv 2: 解锁角色专属活动
  - Lv 4: 解锁角色支线任务
  - Lv 6: 角色在大任务中提供帮助
  - Lv 8: 解锁角色个人危机事件
  - Lv 10: 解锁角色结局
- **好感度衰减**: 长时间不互动会缓慢下降
- **角色互斥**: 某些角色好感度过高会影响其他角色

#### 事件系统
**事件类型**:
1. **主线事件** - 自动触发，推进主要剧情
2. **支线事件** - 角色相关，有时间窗口
3. **随机事件** - 增加不确定性和重玩价值
4. **一次性事件** - 错过不会再出现
5. **循环事件** - 每周/定期可重复

**事件触发条件**:
```json
{
  "date_range": [10, 20],
  "time_slot": "afternoon",
  "required_attributes": {
    "knowledge": 3,
    "courage": 2
  },
  "required_relationship": {
    "character_id": "char_01",
    "level": 4
  },
  "required_flags": ["event_01_completed"],
  "random_chance": 0.3
}
```

## 世界观设定

### 时代背景

**年份**: 2045年
**地点**: 新东京 (Neo-Tokyo)，一个高度科技化的超级都市

### 核心设定

#### MindLink 技术
- **发明时间**: 2038年
- **功能**: 脑机接口技术，可以让人类意识进入数字空间
- **普及度**: 全球60%人口安装，年轻人接近100%
- **用途**: 虚拟办公、学习、娱乐、治疗

#### 认知空间 (Cognitive Space)
- **定义**: 每个人潜意识构成的内心世界
- **表现形式**: 视觉化的记忆、情感和心理防御机制
- **正常状态**: 普通人无法察觉或进入
- **崩溃状态**: 认知空间紊乱，表现为失忆、人格改变、昏迷

#### 认知崩溃事件
- **开始时间**: 游戏开始前3个月
- **受害者**: 已有127人，呈指数增长
- **官方说法**: 技术故障，正在调查
- **真相**: 与"集体意识计划"有关（多周目解锁）

### 主要势力

#### 1. NeuroCorp（神经联合公司）
- MindLink 技术的开发者和垄断者
- 表面上在调查崩溃事件
- 内部分为不同派系

#### 2. 认知调查部 (Cognitive Investigation Unit)
- 政府成立的特别部门
- 调查认知崩溃事件
- 主角的导师属于此组织

#### 3. 解放阵线 (Liberation Front)
- 反对 MindLink 技术的激进组织
- 认为技术是精神控制工具
- 部分角色与其有关联

#### 4. 学生会
- 主角所在学校的学生组织
- 看似普通，实则卷入事件
- 几个核心角色是成员

## 游戏流程

### 开场（Day 1-3）

**剧情目标**: 建立世界观，介绍基础机制

1. **Day 1**:
   - 游戏开始，主角醒来，MindLink 装置故障
   - 教程：时间管理基础
   - 遇到第一个角色（青梅竹马）

2. **Day 2**:
   - 学校日常，介绍属性系统
   - 目睹第一个认知崩溃事件（NPC）
   - 解锁"认知空间"概念

3. **Day 3**:
   - 强制进入教程认知空间（梦境形式）
   - 学习基础战斗和解谜
   - 遇到神秘引导者（后期揭示身份）

### 第一章（Day 4-15）："觉醒"

**大任务**: 拯救第一个认知崩溃受害者（同学）
**截止日期**: Day 15
**可用天数**: 12天

**玩家需要**:
- 提升基础属性（战斗力至少Lv2）
- 收集关于受害者的情报
- 与至少2个角色建立联系
- 准备装备和消耗品

**结果**:
- 成功：受害者恢复，获得重要线索，解锁新区域
- 失败：受害者成为植物人，剧情走向Bad End分支

### 第二章（Day 16-35）："日常与异常"

**大任务**:
- Day 25: 拯救第二个受害者（学生会成员）
- Day 35: 拯救第三个受害者（教师）

**剧情发展**:
- 建立角色关系网
- 解锁多个角色线
- 揭示 NeuroCorp 的可疑行为
- 主角能力增强，解锁新技能

**关键选择点**:
- 是否接受政府部门的招募
- 是否信任某个"内部人士"
- 如何分配时间（某些角色线开始互斥）

### 第三章（Day 36-60）："真相浮现"

**大任务**:
- Day 45: 潜入 NeuroCorp 认知实验室
- Day 60: 拯救重要角色（基于好感度，可能是不同人）

**剧情发展**:
- 发现"集体意识计划"的存在
- 主要角色面临个人危机
- 解锁隐藏区域和高级战斗
- 多个势力的立场明朗化

**关键选择点**:
- 是否公开真相
- 是否接受某个角色的"提议"
- 属性和好感度检查（失败可能导致角色死亡）

### 第四章（Day 61-85）："倒计时"

**大任务**:
- Day 70: 阻止内部叛徒
- Day 85: 大规模认知崩溃危机

**剧情发展**:
- 幕后黑手身份揭示
- 集体意识计划的真正目的
- 玩家必须选择站队
- 无法拯救所有人（强制选择）

**时间压力**:
- 多个紧急事件同时发生
- 必须舍弃某些角色线
- 属性不足可能导致失败

### 终章（Day 86-100）："终末与新生"

**大任务**: Day 100 - 最终决战

**结局分支点**:
根据以下因素决定结局：
1. 完成的任务数量（6个大任务的完成情况）
2. 存活的关键角色数量
3. 主角属性总和
4. 与8个角色的关系总和
5. 关键选择（10+ 个剧情选择）
6. 隐藏条件（"回忆碎片"收集数）

**可能的最终任务**:
- 路线A：进入主谋的认知空间，终极战斗
- 路线B：集体意识空间，拯救全人类意识
- 路线C：时间回溯（类似命运石之门）
- 路线D：接受"新世界"（黑化结局）

## 目标受众

### 主要受众

**核心玩家画像**:
- **年龄**: 18-35岁
- **性别**: 男女均衡
- **游戏偏好**:
  - 喜欢日式RPG（女神异闻录系列、轨迹系列）
  - 喜欢视觉小说（命运石之门、Ever17）
  - 喜欢策略和管理（火纹、光荣游戏）
- **游玩习惯**: 愿意多周目，享受收集和探索
- **付费意愿**: 中高（$10-30 for full game）

### 次要受众

- 喜欢科幻悬疑题材的泛游戏玩家
- 喜欢角色扮演和恋爱养成的玩家
- 移动平台的核心玩家

## 竞品分析

### 直接竞品

#### 女神异闻录5 (Persona 5)
**借鉴**:
- 时间管理系统
- 日常 + 战斗双循环
- 社群（好感度）系统
- 美术风格化表现

**差异化**:
- 移动平台优化（更短的游戏时长）
- 更强调"选择的代价"
- 科幻而非奇幻设定
- 更轻量的战斗系统

#### 命运石之门 (Steins;Gate)
**借鉴**:
- 多周目解谜机制
- 科幻悬疑氛围
- 角色深度塑造
- 真结局的设计

**差异化**:
- 增加玩法元素（不是纯视觉小说）
- 时间管理压力
- 战斗和解谜内容

### 间接竞品

- **火焰纹章：风花雪月** - 学院时间管理
- **AI:梦境档案** - 解谜 + 视觉小说混合
- **十三机兵防卫圈** - 多角色叙事

## 技术需求

### 平台要求

**最低配置** (移动端):
- iOS 13+ / Android 8.0+
- 2GB RAM
- 1.5GB 存储空间

**推荐配置**:
- iOS 15+ / Android 11+
- 4GB RAM
- 2GB 存储空间

### 关键技术点

1. **存档系统** - 支持多存档位，云同步
2. **本地化系统** - 多语言支持，文本量约 50万字
3. **性能优化** - 确保在中低端设备流畅运行
4. **UI适配** - 支持多种屏幕比例和分辨率

## 商业模式

### 定价策略

**推荐**: Premium + DLC 模式

- **基础游戏**: $9.99 - $14.99
  - 完整100天流程
  - 6个主要角色线
  - 10个基础结局

- **DLC/扩展内容**:
  - 额外角色包: $2.99 (2个新角色)
  - 服装/外观包: $1.99
  - 支线任务包: $4.99
  - "真相路线"扩展: $6.99

**替代方案**:
- 免费游戏 + 章节付费
- 订阅制（不推荐，影响叙事体验）

### 预期表现

**保守估计**:
- 首月下载: 10,000
- 转化率: 15% (premium model)
- 首年营收: $15,000 - $30,000

**乐观估计**:
- 如果获得媒体关注/口碑爆发
- 首年营收: $100,000+

## 风险评估

### 高风险

1. **开发时间超期** - 内容量大，单人开发
   - **缓解**: 使用模块化设计，优先完成垂直切片

2. **平衡性问题** - 时间管理系统难以平衡
   - **缓解**: 早期测试，数据驱动调整

### 中风险

3. **叙事质量** - 50万字剧本质量难以保证
   - **缓解**: 分章节迭代，重点打磨关键情节

4. **技术债务** - 快速开发可能导致代码混乱
   - **缓解**: 严格的代码规范和架构设计

### 低风险

5. **市场竞争** - 移动端同类产品较少
6. **技术实现** - 使用成熟引擎和技术
