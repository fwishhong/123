## 结局概览

### 设计理念

**"选择决定命运"**

- ✅ 多维度评估 - 不是单一数值决定
- ✅ 有好有坏 - 不是所有结局都完美
- ✅ 重玩价值 - 真结局需要多周目
- ✅ 情感共鸣 - 每个结局都有意义

### 结局总数

**总计**: 18个结局

| 类型 | 数量 | 说明 |
|------|------|------|
| 主线结局 | 5个 | 基于主线选择和完成度 |
| 角色结局 | 8个 | 与特定角色的结局（可组合） |
| 特殊结局 | 3个 | 隐藏/黑化/喜剧结局 |
| 真结局 | 2个 | 多周目解锁 |

**结局可组合**:
- 主线结局 + 角色结局 = 40+ 种组合
- 例如："理想结局" + "晓的恋爱结局"

## 结局分类

### A类: 主线结局（5个）

这些结局基于Day 100的最终战和整体表现。

#### A1: Bad Ending - "崩溃的世界"

**触发条件**:
- 完成任务数 ≤ 3
- 或存活角色数 ≤ 3
- 或最终战败北

**剧情**:
```
集体意识计划启动成功
世界陷入混沌
主角无力阻止
90%人类进入永久认知空间
主角带着少数幸存者逃离城市
留下的是一片废墟
```

**演出**:
- 黑白色调的CG
- 悲伤的BGM
- 存活角色的哀悼
- "游戏结束"画面
- 提示：读取存档或降低难度重试

**解锁**:
- 无奖励
- 标记为Bad End
- 鼓励玩家重试

---

#### A2: Normal Ending - "代价"

**触发条件**:
- 完成任务数 = 4-5
- 存活角色数 = 4-6
- 选择"对抗Dr.天城"路线
- 最终战胜利

**剧情**:
```
Day 100决战:
主角击败了Dr.天城
集体意识计划被破坏
但天城在临死前启动了部分功能
城市的20%人口受到影响

结局:
- 主角成为英雄，但付出了代价
- 部分角色死亡/昏迷（未救的角色）
- 幸存者们继续生活
- 暗示：仍有潜在威胁

后日谈:
- 一年后，主角在纪念碑前
- 悼念失去的人们
- 决心继续守护这个世界
- 镜头拉远，主角并不孤单（幸存角色陪伴）
```

**演出**:
- 苦乐参半的CG
- 英雄主题BGM
- 展示每个角色的结局（生存/死亡）
- Staff Roll
- NG+解锁提示

**解锁**:
- 新游戏+模式
- 隐藏技能
- 概念美术图鉴

---

#### A3: Good Ending - "新的开始"

**触发条件**:
- 完成全部6个任务
- 存活角色数 ≥ 7
- 主角属性总和 ≥ 30
- 好感度总和 ≥ 50
- 选择"对抗路线"并胜利

**剧情**:
```
Day 100决战:
主角和团队击败Dr.天城
成功阻止集体意识计划
几乎所有人都存活下来

结局:
- 认知崩溃事件停止
- NeuroCorp被解散重组
- 咲良帮助改革认知调查部
- 主角和伙伴们成为新秩序的守护者

后日谈:
- 半年后，主角重返校园
- 与所有角色的日常互动（温馨）
- 新的威胁出现（伏笔）
- 但主角已经不再是一个人

最终画面:
- 全员集合照
- "谢谢你拯救了我们"
```

**演出**:
- 彩色明亮的CG
- 每个角色的幸福场景
- 温暖的BGM
- 详细的后日谈
- Staff Roll + NG+提示

**解锁**:
- NG+模式
- 隐藏剧情选项
- 真结局提示
- 奖励道具（NG+起始）

---

#### A4: Ideal Ending - "共存"

**触发条件**:
- 完成全部6个任务
- 存活角色数 = 8（全部）
- 主角知识等级 ≥ 9
- 收集全部"真相碎片"（隐藏收集品）
- 选择"说服Dr.天城"路线（Day 99特殊对话）

**剧情**:
```
Day 99:
主角找到了Dr.天城女儿的认知空间备份
揭示了天城的真正痛苦
主角提出：不是消灭个体意识，而是治愈它

Day 100:
与天城合作对抗真正的幕后黑手（系统AI）
最终战：vs 失控的MindLink系统

结局:
- 天城牺牲自己，拯救了女儿的意识
- 集体意识计划被改良为"认知治疗系统"
- 认知崩溃的受害者全部恢复
- MindLink技术被正确使用

后日谈:
- 一年后，新的世界
- 认知空间成为治疗心理疾病的工具
- 主角成为"认知医师"
- 天城的女儿醒来，感谢主角
- 和平的未来

最终画面:
- 全员 + 复活的NPC
- "这就是最好的结局"
```

**演出**:
- 史诗级的BOSS战
- 感人的牺牲场景
- 完美的后日谈（所有人幸福）
- 特殊ED曲
- 制作人员感谢

**解锁**:
- 特殊称号："理想主义者"
- 全部隐藏内容
- 真结局提示（更明显）

---

#### A5: True Ending - "因果的尽头" (多周目限定)

**触发条件**:
- **必须**: 至少完成一次Good Ending或Ideal Ending
- NG+模式
- 收集全部8个"回忆碎片"（NG+专属道具）
- Day 99选择"启动时间回溯"（NG+专属选项）
- 达成特定角色对话组合

**剧情**:
```
Day 99:
主角使用时间回溯能力
回到了Day 1之前——主角昏迷的那三天

真相揭示:
- 主角的昏迷并非意外
- 是"另一个主角"（失败的未来）回溯时间导致
- 当前的100天，已经是第N次循环
- Dr.天城、神代教授都察觉到了异常
- 真正的敌人是"绝望的未来"

Day 100:
最终战：vs "可能性的终点"（概念BOSS）
- 代表所有失败的未来
- 必须用羁绊（好感度）的力量击败

结局:
- 打破因果循环
- 创造了"第一次"真正的未来
- 所有角色保留了模糊的记忆（既视感）
- 主角失去了时间回溯能力

后日谈:
- 这一次，没有认知崩溃
- 没有集体意识计划
- 只有平凡的校园生活
- 但主角和伙伴们的羁绊依然存在

最终画面:
- Day 1的早晨（对比开场）
- "这次，让我们创造不需要重来的未来"
- 全新的开始
```

**演出**:
- 多时间线蒙太奇
- 揭示所有伏笔的答案
- 最难的BOSS战
- 情感高潮的对话
- 完美的闭环叙事
- 特殊True ED曲

**解锁**:
- 最终称号："因果破坏者"
- 完整图鉴
- 开发者彩蛋
- 感谢游玩画面

### B类: 角色结局（8个）

每个可攻略角色有独立结局，可以与主线结局组合。

**触发条件** (通用):
- 该角色存活
- 好感度 Lv 10
- 完成角色专属事件链
- Day 90+与该角色的最终对话

#### B1: 晓的结局 - "永远在一起"

**类型**: 恋爱结局

**剧情**:
```
Day 95:
晓在夕阳下向主角告白
"从小时候起，我就想一直在你身边"

结局后日谈:
- 一起面对未来
- 成为搭档（恋人或伙伴）
- 她成为了职业运动员
- 主角永远支持她

CG:
- 夕阳下的拥抱
- 婚礼（如果选择恋爱路线）
- 或搭档的握手（友情路线）
```

#### B2-B8: 其他角色结局

每个角色类似结构，提供：
- 独特的告白/表白/确认场景
- 角色个人的未来走向
- 与主角的关系（恋爱/友情/师徒）
- 专属CG

**示例**:
- 零: 一起追求真相，成为研究伙伴
- 美月: 找到自我，成为独立的艺术家
- 咲良: 改革组织，主角成为她的助手
- ...等等

### C类: 特殊结局（3个）

#### C1: Dark Ending - "新世界"

**触发条件**:
- Day 99选择"接受计划"
- 主角精神崩溃（特定对话选择）
- 或主角好感度总和 < 20（孤立）

**剧情**:
```
主角被天城说服
接受了集体意识计划
Day 100，主动帮助天城

结局:
- 计划成功
- 全人类意识统合
- 没有痛苦，没有悲伤，也没有个性
- 主角成为"新世界"的守护者
- 但失去了一切

画面:
- 黑白的"完美"世界
- 失去表情的人们
- 主角独自站在高处
- "这真的是我想要的吗？"

恐怖暗示:
- 所有人都是一样的微笑
- 诡异的和谐
- 反乌托邦
```

**解锁**:
- 称号："新世界的神"
- 成就解锁
- 不推荐结局，但是内容很丰富

---

#### C2: Joke Ending - "摸鱼大师"

**触发条件**:
- 拒绝所有主线任务
- 只做日常活动
- Day 100不参与最终战

**剧情**:
```
主角完全放弃拯救世界
只专注于自己的生活
Day 100，躲在家里

结局:
- 世界毁灭了
- 但主角的属性全部Lv10
- 金钱999999
- 所有道具收集完毕

画面:
- 世界崩溃的背景
- 主角在家里打游戏
- "虽然世界毁灭了，但我的数值是满的"
- 恶搞式的演出

旁白:
- "你获得了最强的主角"
- "但失去了一切"
- "这就是你想要的吗？"
- "...真的吗？"
- "好吧，至少你玩得开心"
```

**解锁**:
- 称号："摸鱼冠军"
- 成就："错误的游戏方式"
- 纯彩蛋性质

---

#### C3: Secret Ending - "开发者的房间"

**触发条件**:
- 收集所有隐藏彩蛋（20个）
- 在特定日期做特定事情（隐藏解谜）
- 达成特定条件组合（社区发现）

**剧情**:
```
主角突然发现了"第四面墙"
意识到自己在游戏中

进入开发者房间:
- 可以查看所有数据
- 与"开发者"对话（第四墙打破）
- 了解游戏的制作过程

彩蛋内容:
- 开发趣事
- 废案设计
- 制作人员留言
- 感谢玩家的话

返回游戏:
- 可以继续正常流程
- 获得"真理之眼"道具（能看到数值）
```

**解锁**:
- 称号："真理探求者"
- 开发者评论模式
- 隐藏美术图

## 触发条件

### 结局判定系统

**Day 100决战后，系统进行判定**:

```python
# 伪代码
def determine_ending():
    # 1. 检查特殊条件
    if player.chose_join_plan:
        return DarkEnding

    if player.refused_all_missions:
        return JokeEnding

    if player.has_time_rewind_power and player.collected_all_memory_fragments:
        return TrueEnding

    # 2. 检查失败条件
    if player.missions_completed <= 3 or player.alive_characters <= 3:
        return BadEnding

    # 3. 检查理想结局
    if (player.missions_completed == 6 and
        player.alive_characters == 8 and
        player.knowledge >= 9 and
        player.chose_convince_amagi):
        return IdealEnding

    # 4. 检查好结局
    if (player.missions_completed == 6 and
        player.alive_characters >= 7 and
        player.total_attributes >= 30 and
        player.total_relationships >= 50):
        return GoodEnding

    # 5. 默认普通结局
    return NormalEnding

def determine_character_endings():
    character_endings = []
    for character in characters:
        if character.alive and character.relationship == 10:
            if player.saw_final_event(character):
                character_endings.append(character.ending)
    return character_endings

# 最终结局 = 主线结局 + 角色结局组合
final_ending = (determine_ending(), determine_character_endings())
```

### 条件权重

| 因素 | 权重 | 说明 |
|------|------|------|
| 任务完成数 | 35% | 最重要 |
| 角色存活数 | 30% | 关系很重要 |
| 主角属性 | 15% | 能力影响 |
| 好感度总和 | 15% | 羁绊影响 |
| 特殊选择 | 5% | 关键对话 |

## 结局内容

### 结局演出流程

```
最终战胜利/失败
    ↓
判定结局类型
    ↓
播放结局动画 (3-5分钟)
    ├─ Opening: 战后场景
    ├─ Main: 主要剧情
    ├─ Character: 角色后日谈 (每个30秒)
    └─ Ending: 最终画面
    ↓
Staff Roll (制作人员表)
    ↓
后日谈CG (3-5张)
    ↓
结局统计画面
    ├─ 达成的结局
    ├─ 游玩时间
    ├─ 完成度
    ├─ 存活角色
    ├─ 解锁成就
    └─ NG+提示
    ↓
返回主菜单 (带完成标记)
```

### 结局CG数量

| 结局类型 | CG数量 | 说明 |
|---------|--------|------|
| Bad Ending | 2张 | 简单 |
| Normal Ending | 4张 | 基础后日谈 |
| Good Ending | 6张 | 详细后日谈 |
| Ideal Ending | 8张 | 完整后日谈 |
| True Ending | 10张 | 多时间线 |
| 角色结局 | 2张/角色 | 共16张 |
| 特殊结局 | 3张 | 彩蛋 |

**总CG数**: 约50张

## 多周目设计

### 第一周目

**目标**: 体验主要剧情
**推荐**: Normal/Good Ending
**解锁**: NG+模式

### 第二周目

**目标**: 收集遗漏的角色线
**推荐**: Ideal Ending + 不同角色结局
**解锁**: 回忆碎片提示

### 第三周目+

**目标**: 真结局和完美收集
**推荐**: True Ending
**解锁**: 全部内容
