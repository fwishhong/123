## 设计目标

### 核心理念

**"简单易上手，策略有深度"**

- ✅ 移动端友好 - 触控操作简单直观
- ✅ 回合制 - 可以随时暂停思考
- ✅ 快节奏 - 单场战斗 2-5 分钟
- ✅ 策略性 - 属性搭配、技能连携、队友配合
- ✅ 叙事服务 - 战斗是剧情的一部分，不是独立玩法

### 设计参考

- **女神异闻录5** - 弱点系统、连携攻击
- **勇者斗恶龙** - 简洁的回合制
- **FTL** - 快速决策和风险管理

## 战斗流程

### 战斗触发

**触发方式**:
1. **剧情战斗** - 主线/支线任务中的固定战斗
2. **探索战斗** - 在认知空间探索时遇敌
3. **BOSS战** - 每个大任务的最终战

### 战斗开始

```
1. 战斗转场动画 (0.5秒)
   ↓
2. 显示敌人信息
   - 敌人名称和类型
   - 危险等级提示
   ↓
3. 队伍编成 (如果允许)
   - 选择最多3名角色
   - 查看敌人弱点（如果已知）
   ↓
4. 战斗开始
```

### 回合结构

```
┌────── 回合开始 ──────┐
│                      │
│  1. 判定行动顺序     │ ← 基于速度属性
│      (Speed)         │
│         ↓            │
│  2. 玩家回合         │
│    - 选择行动        │
│    - 执行动作        │
│    - 计算结果        │
│         ↓            │
│  3. 敌人回合         │
│    - AI选择行动      │
│    - 执行攻击        │
│    - 计算伤害        │
│         ↓            │
│  4. 回合结束         │
│    - 检查胜负        │
│    - 处理持续效果    │
│    - 回复SP          │
│                      │
└────── 下一回合 ──────┘
```

### 战斗结束

**胜利条件**:
- 消灭所有敌人

**失败条件**:
- 主角HP归零

**结算**:
```
胜利
 ↓
显示战果
 ├─ 获得经验值
 ├─ 获得金钱
 ├─ 获得道具（可能）
 └─ 角色成长提示
 ↓
返回探索 / 剧情继续

失败
 ↓
Game Over 选项
 ├─ 重新战斗（从战斗开始）
 ├─ 降低难度重试
 └─ 读取存档
```

## 战斗机制

### 角色属性

每个战斗单位有以下属性：

| 属性 | 说明 | 影响 |
|------|------|------|
| **HP** | 生命值 | 归零即战斗不能 |
| **SP** | 技能点 | 使用技能消耗 |
| **ATK** | 攻击力 | 物理伤害 |
| **DEF** | 防御力 | 减少物理伤害 |
| **MAG** | 魔力 | 特殊攻击伤害 |
| **RES** | 抗性 | 减少特殊伤害 |
| **SPD** | 速度 | 决定行动顺序、回避率 |
| **LUK** | 幸运 | 暴击率、掉落率 |

**属性计算公式**:
```
基础 HP = 100 + (战斗力等级 × 20)
基础 SP = 50 + (知识等级 × 5)
ATK = 10 + (战斗力等级 × 3) + 装备加成
DEF = 5 + (勇气等级 × 2) + 装备加成
MAG = 5 + (知识等级 × 3)
RES = 5 + (魅力等级 × 2)
SPD = 50 + (角色基础速度) + 装备
```

### 行动类型

玩家每回合可选择：

#### 1. 攻击 (Attack)
- **消耗**: 0 SP
- **效果**: 对单个敌人造成物理伤害
- **伤害**: ATK × (1.0 ~ 1.2) - 敌人DEF × 0.5
- **特殊**: 可能触发暴击 (LUK/100 概率，伤害×1.5)

#### 2. 技能 (Skill)
- **消耗**: 5-30 SP
- **效果**: 根据技能不同
  - 攻击技能：高伤害、范围攻击、属性攻击
  - 辅助技能：BUFF、DEBUFF、治疗
  - 特殊技能：独特效果

**技能示例**:
```json
{
  "id": "skill_lightning_strike",
  "name": "雷霆一击",
  "sp_cost": 15,
  "type": "attack",
  "element": "electric",
  "target": "single_enemy",
  "power": 150,
  "description": "电属性攻击，对机械敌人额外伤害"
}
```

#### 3. 道具 (Item)
- **消耗**: 道具数量
- **效果**:
  - 回复HP/SP
  - 移除负面状态
  - 临时BUFF

#### 4. 防御 (Guard)
- **消耗**: 0 SP
- **效果**: 本回合受到伤害减半，恢复 5% 最大SP

#### 5. 逃跑 (Escape)
- **条件**: 非BOSS战，非剧情战
- **成功率**: 基于SPD差距，50%-90%
- **失败**: 浪费该回合

### 属性相克系统

认知空间中存在5种元素：

```
物理 (Physical) ←→ 精神 (Mental)
  ↓                    ↓
电子 (Digital)   情感 (Emotional)
      ↖          ↙
       记忆 (Memory)
```

**相克关系**:
- 物理 → 数字（克制）
- 数字 → 情感（克制）
- 情感 → 记忆（克制）
- 记忆 → 精神（克制）
- 精神 → 物理（克制）

**效果**:
- **克制**: 伤害 ×1.5，可能造成"倒地"
- **抵抗**: 伤害 ×0.5
- **无效**: 伤害 0

### 倒地与追击系统

**倒地 (Down)**:
- 触发条件：被弱点属性攻击
- 效果：
  - 该敌人失去下一回合行动
  - 攻击者获得"再行动"机会（额外一次行动）
  - 可以连锁触发

**战术应用**:
```
玩家发现敌人弱点
  ↓
使用克制属性技能
  ↓
敌人倒地，获得再行动
  ↓
可以：
  1. 继续攻击倒地敌人（总攻击）
  2. 攻击其他敌人
  3. 切换角色行动

如果多个敌人倒地 → 触发"总攻击"(All-Out Attack)
```

### 总攻击 (All-Out Attack)

**触发条件**: 所有敌人都处于倒地状态

**效果**:
- 全体队友对所有敌人发动强力合击
- 伤害 = 队伍总ATK × 2
- 华丽的演出动画（2秒）
- 战斗快速结束（适合清理杂兵）

### 队友支援系统

**支援触发**:
- 条件：角色好感度 ≥ 6
- 触发率：(好感度 - 5) × 10%
- 效果：随机触发支援行动

**支援类型**:

1. **连携攻击**
   - 队友追加一次攻击
   - 伤害为其ATK × 80%

2. **掩护**
   - 替主角承受致命伤害
   - 队友受到50%伤害

3. **治疗**
   - 恢复主角 30% HP

4. **鼓舞**
   - 主角下次攻击伤害 +50%

## 角色系统

### 主角

**特点**: 全能型，可以学习多种技能

**成长**:
- 战斗力等级提升 → HP、ATK增加
- 知识等级提升 → SP、MAG增加
- 勇气等级提升 → DEF增加
- 魅力等级提升 → 支援触发率增加

**技能习得**:
- 等级提升自动学习基础技能
- 完成特定事件解锁特殊技能
- 角色好感度解锁连携技

### 队友角色（8人）

每个角色有独特定位：

#### 角色原型

1. **坦克型** - 高HP高DEF，保护队友
2. **输出型** - 高ATK，爆发伤害
3. **法师型** - 高MAG，属性攻击
4. **辅助型** - 治疗、BUFF
5. **速度型** - 高SPD，先手控制
6. **全能型** - 平衡，适应性强
7. **技巧型** - 特殊效果，DEBUFF
8. **暴击型** - 高LUK，不稳定但上限高

**队友能力受好感度影响**:
```
Lv 1-3: 无法参战
Lv 4-5: 可以参战，基础能力
Lv 6-7: 解锁专属技能
Lv 8-9: 能力提升20%
Lv 10:  解锁终极技能，支援必定触发
```

## 敌人设计

### 敌人分类

#### 1. 杂兵 (Mob)
- HP: 50-150
- 特点: 弱，数量多（2-4只）
- 掉落: 少量金钱和经验
- 用途: 快速战斗，测试玩家掌握

#### 2. 精英 (Elite)
- HP: 200-400
- 特点: 有特殊技能，1-2只出现
- 掉落: 道具、较多经验
- 用途: 考验策略和资源管理

#### 3. BOSS
- HP: 800-2000
- 特点: 多阶段、特殊机制、弱点变化
- 掉落: 稀有道具、大量经验、剧情道具
- 用途: 高潮战斗，剧情关键

### 敌人主题（认知空间的具现化）

| 主题 | 外观 | 含义 | 弱点 |
|------|------|------|------|
| **记忆碎片** | 破碎的几何体 | 遗忘的记忆 | 情感 |
| **压力幻影** | 扭曲的人形 | 心理压力 | 精神 |
| **防御机制** | 机械护卫 | 心理防御 | 物理 |
| **恐惧实体** | 黑暗怪物 | 内心恐惧 | 勇气相关 |
| **执念** | 重复的影像 | 放不下的过去 | 记忆 |

### BOSS机制示例

**第一个BOSS: "遗忘之墙"**

**背景**: 第一个受害者的认知防御，阻止记忆恢复

**阶段1** (100% - 60% HP):
- 普通攻击
- 召唤"记忆碎片"小怪
- 弱点: 情感属性

**阶段2** (60% - 30% HP):
- 使用"记忆封锁"（全体伤害）
- 防御力提升
- 弱点变为: 物理属性
- 提示: "用真实的力量击碎虚幻的防御"

**阶段3** (30% - 0% HP):
- 狂暴状态，攻击力大幅提升
- 使用终极技"完全遗忘"（需要防御或打断）
- 无弱点，但HP较低
- 考验资源管理和生存

**胜利后**:
- 剧情CG：记忆恢复
- 主角获得新技能："记忆共鸣"

## 平衡性

### 难度设计

**三档难度**:

| 难度 | 敌人HP | 敌人伤害 | 金钱掉落 | 说明 |
|------|--------|---------|---------|------|
| **简单** | 70% | 70% | 120% | 享受剧情，战斗简单 |
| **普通** | 100% | 100% | 100% | 推荐难度，有挑战 |
| **困难** | 150% | 130% | 80% | 高挑战，策略要求高 |

**动态难度**:
- 连续失败3次 → 提示降低难度
- BOSS战可以选择"重试并降低难度"

### 经验值和等级

**等级上限**: 主角属性 1-10 级

**升级所需经验** (指数增长):
```
Lv 1→2: 100 EXP
Lv 2→3: 200 EXP
Lv 3→4: 400 EXP
Lv 4→5: 700 EXP
Lv 5→6: 1200 EXP
Lv 6→7: 2000 EXP
Lv 7→8: 3200 EXP
Lv 8→9: 5000 EXP
Lv 9→10: 8000 EXP
```

**经验获取**:
- 杂兵: 20-50 EXP
- 精英: 100-200 EXP
- BOSS: 500-1000 EXP
- 任务奖励: 200-500 EXP

**平衡目标**:
- Day 15 (第一个BOSS): 战斗力 Lv 2-3
- Day 35: 战斗力 Lv 4-5
- Day 60: 战斗力 Lv 6-7
- Day 100: 战斗力 Lv 8-10（取决于玩家选择）

### 伤害计算

```csharp
public int CalculateDamage(Combatant attacker, Combatant defender, Skill skill)
{
    float baseDamage = attacker.ATK * skill.PowerMultiplier;

    // 防御减伤
    float defense = defender.DEF * 0.5f;

    // 属性克制
    float elementMultiplier = GetElementMultiplier(skill.Element, defender.Weakness);

    // 随机波动 (90% - 110%)
    float randomFactor = Random.Range(0.9f, 1.1f);

    // 暴击判定
    bool isCritical = Random.value < (attacker.LUK / 100f);
    float critMultiplier = isCritical ? 1.5f : 1.0f;

    int finalDamage = Mathf.Max(1,
        (int)((baseDamage - defense) * elementMultiplier * randomFactor * critMultiplier)
    );

    return finalDamage;
}
```
