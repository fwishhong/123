## 设计目标

### 核心理念

**"手机友好，叙事驱动"**

- ✅ 触屏操作 - 避免需要精确操作的解谜
- ✅ 可暂停 - 可以随时退出思考
- ✅ 有提示 - 不会卡关太久
- ✅ 服务剧情 - 解谜是认知空间的具现化，有意义
- ✅ 可选难度 - 部分解谜可以用战斗代替

### 设计原则

1. **清晰的目标** - 玩家始终知道要做什么
2. **逐步引导** - 从简单到复杂
3. **失败宽容** - 失败不会惩罚太重
4. **节奏控制** - 解谜时长 2-10 分钟

## 解谜类型

### 类型 1: 逻辑推理

**描述**: 通过线索推理出答案

**适合场景**:
- 侦查阶段：收集情报
- 认知空间：理解心结

**手机适配**: 点击选择即可，无操作难度

#### 子类型 A: 证据组合

**玩法**:
- 提供 5-8 条线索
- 玩家选择 2-3 条关键线索组合
- 找出正确的推理链

**示例**:
```
场景: 调查第一个受害者

线索:
1. 受害者最近工作压力大
2. 他的MindLink使用时间剧增
3. 办公桌上有安眠药
4. 同事说他最近很焦虑
5. 他的认知空间充满"遗忘"符号

问题: 认知崩溃的诱因是？

正确组合: 2+4+5
→ 他因焦虑过度使用MindLink逃避，导致认知紊乱
```

**UI设计**:
```
┌─────────────────────────┐
│   选择关键线索 (3个)    │
├─────────────────────────┤
│ □ 线索1: 工作压力大     │
│ ☑ 线索2: MindLink剧增   │
│ □ 线索3: 安眠药         │
│ ☑ 线索4: 焦虑           │
│ ☑ 线索5: 遗忘符号       │
│ □ 线索6: ...            │
├─────────────────────────┤
│      [提交答案]         │
└─────────────────────────┘
```

#### 子类型 B: 对话推理

**玩法**:
- 与NPC对话
- 发现矛盾
- 用证据指出

**示例** (逆转裁判式):
```
NPC: "那天晚上我一直在家。"

证据:
- 监控录像显示他外出过
- 点击"监控录像"
- "这和你的证词矛盾！"

NPC: "好吧...我确实出门了..."
→ 解谜进展
```

### 类型 2: 密码破解

**描述**: 破解数字/文字密码

**适合场景**:
- 进入认知空间深层
- 解锁隐藏记忆

**手机适配**: 输入数字/选择符号

#### 子类型 A: 数字密码

**玩法**:
- 提供线索
- 推导出4位数字密码

**示例 1 - 日期密码**:
```
场景: 受害者的保险箱

线索:
- 墙上日历圈出了"7月15日"
- 照片上写着"我们的纪念日"
- 提示: "对她最重要的日子"

密码: 0715

UI: 数字键盘输入
```

**示例 2 - 计算密码**:
```
场景: 认知空间的门

提示:
"记忆的总和"
- 第一次见面: 12岁
- 第一次约会: 16岁
- 现在: 17岁

密码: 12+16+17 = 45

密码: 45
```

#### 子类型 B: 符号密码

**玩法**:
- 识别符号模式
- 选择正确的符号序列

**示例**:
```
场景: 认知空间的符文锁

显示:
♠ ♣ ♥ ? ♠ ♣

规律: 重复序列
答案: ♦

UI: 点击选择符号
```

### 类型 3: 模式识别

**描述**: 找出图案/序列规律

**适合场景**:
- 记忆修复
- 认知空间导航

**手机适配**: 点击/滑动

#### 子类型 A: 序列补全

**玩法**:
- 给出部分序列
- 找出规律并补全

**示例**:
```
记忆碎片序列:
[开心] → [?] → [悲伤] → [愤怒]

选项:
A. 焦虑
B. 平静
C. 困惑

答案: C (情绪递进: 开心→困惑→悲伤→愤怒)
```

#### 子类型 B: 图像匹配

**玩法**:
- 找出一组图像中的规律
- 选择不匹配的

**示例**:
```
4张记忆图片:
1. 家庭聚餐（父母+主角）
2. 生日派对（父母+主角）
3. 游乐园（父母+主角）
4. 毕业典礼（只有主角）

问题: 哪个记忆是"虚假"的？
答案: 4 (父母缺席 = 创伤记忆)
```

### 类型 4: 空间解谜

**描述**: 移动物体、走迷宫

**适合场景**:
- 认知空间探索
- 解锁新区域

**手机适配**: 简化操作，避免复杂

#### 子类型 A: 简化推箱子

**玩法**:
- 移动方块到目标位置
- 最多3-4步解决
- 不会太复杂

**示例**:
```
3x3网格:
□ □ □
□ ■ □  (■ = 箱子)
○ □ □  (○ = 目标)

点击箱子，选择方向
→ 移动到目标

最多允许3-5个箱子
步数限制宽松
```

#### 子类型 B: 路径寻找

**玩法**:
- 找到从A到B的正确路径
- 避开障碍

**示例**:
```
记忆迷宫:
起点 → 分岔1 → 分岔2 → 终点

线索:
"总是选择光明的道路"

每个分岔:
- 明亮的路
- 黑暗的路

答案: 都选明亮的
```

**简化**: 不超过5个选择点

---

### 类型 5: 记忆重组

**描述**: 将打乱的记忆排序

**适合场景**:
- 修复受害者记忆
- 理解事件真相

**手机适配**: 拖拽排序

#### 玩法

**示例**:
```
场景: 受害者的记忆碎片

打乱的记忆:
C. 他大哭
A. 他收到礼物
D. 他把礼物扔掉
B. 他发现礼物是假的

任务: 正确排序

正确顺序: A → B → C → D
(收到→发现→大哭→扔掉)

UI: 拖拽卡片排序
```

---

### 类型 6: 音乐/节奏（可选）

**描述**: 音符匹配

**适合场景**:
- 美月的认知空间
- 音乐相关记忆

**手机适配**: 点击屏幕

#### 玩法

**简化节奏游戏**:
- 播放短旋律（3-5个音符）
- 玩家重复点击
- 容错率高

**示例**:
```
听到: ♪ ♪ ♫ ♪

点击: ○ ○ ● ○
(○=短音, ●=长音)

不需要精确timing，只要顺序对即可
```

## 难度设计

### 难度分级

| 等级 | 特征 | 出现时机 |
|------|------|----------|
| **简单** | 明显提示，3-5分钟 | 任务1-2，教学 |
| **中等** | 需要思考，5-8分钟 | 任务3-4 |
| **困难** | 复杂推理，8-15分钟 | 任务5-6，可选 |
| **隐藏** | 无提示，社区合作 | 彩蛋，真结局 |

### 难度曲线

```
任务1: 2个简单解谜
任务2: 1个简单 + 2个中等
任务3: 3个中等
任务4: 2个中等 + 1个困难
任务5: 2个困难
任务6: 3个困难 + 1个超难（可选）
```

### 自适应难度

**失败次数检测**:
- 失败3次 → 提供更明显的提示
- 失败5次 → 提供"跳过"选项（消耗道具或降低奖励）

## 提示系统

### 三级提示

每个解谜有3级提示：

**示例解谜**: 数字密码 (生日)

```
提示 Lv1: "这个日期对她很重要"
→ 玩家知道是日期

提示 Lv2: "照片上的日期..."
→ 引导玩家看照片

提示 Lv3: "7月15日，就是答案"
→ 直接给答案
```

### 提示获取方式

1. **时间提示**: 思考5分钟后自动提示Lv1
2. **道具提示**: 使用"提示道具"
3. **队友提示**: 高好感度角色提供提示
   - 零(知识型): 逻辑解谜提示
   - 晓(直觉型): 直接告诉答案（魅力）
4. **属性提示**: 主角属性够高自动显示
   - 知识 ≥ 6: 解谜时显示部分答案
   - 魅力 ≥ 6: 可以"蒙混过关"（某些解谜）

## 示例解谜

### 完整示例: 任务1的核心解谜

**背景**: 进入第一个受害者的认知空间，需要找到心结的源头

#### 阶段1: 进入认知空间

**解谜类型**: 密码破解

**场景**:
```
认知空间的大门
上面有一个数字锁

提示: "他最想忘记的那一天"

线索（在准备阶段收集）:
- 同学说他最近总提到"去年的事"
- 他的日记本最后一页: "6月10日...我永远不会原谅自己"
- 照片: 一张撕碎的照片，背面写着"6/10"
```

**解谜**:
```
UI: 数字键盘
输入: 0610
→ 门打开
```

**如果没收集线索**:
- 可以尝试输入
- 3次失败后，零(如果在队伍)提示: "试试他日记里的日期"

---

#### 阶段2: 记忆迷宫

**解谜类型**: 路径选择 + 记忆重组

**场景**:
```
认知空间内部是一个分岔的走廊
每个分岔都有一段记忆播放
```

**解谜**:
```
分岔1:
- 左: 开心的记忆（生日）
- 右: 悲伤的记忆（被骂）

分岔2:
- 左: 平静的记忆（学习）
- 右: 愤怒的记忆（争吵）

分岔3:
- 左: 恐惧的记忆（???）
- 右: 温暖的记忆（家人）

提示: "最痛苦的记忆在最深处"

正确路径: 悲伤 → 愤怒 → 恐惧
→ 到达核心
```

**记忆重组**:
```
到达核心后，看到4个记忆碎片:

D. "我永远无法原谅自己"
B. "我说了不该说的话"
A. "那天我们吵架了"
C. "她离开了我"

任务: 按时间顺序排列

正确: A → B → C → D

完成后，受害者的心结显现:
"她离开是因为我..."
```

---

#### 阶段3: BOSS前的最后解谜

**解谜类型**: 证据组合

**场景**:
```
BOSS (心结的具现化) 出现前
需要先"说服"心结

系统提示: "用真相击碎虚假的自责"
```

**解谜**:
```
心结: "都是我的错，她离开是因为我"

证据:
1. 她的日记: "我必须去照顾生病的母亲"
2. 她的信: "对不起，这不是你的错"
3. 争吵的真相: 是因为她要离开
4. 照片: 她留下了联系方式

任务: 选择正确的证据反驳

正确组合: 1+2
→ "她离开是因为家人，不是因为你"

心结动摇:
→ BOSS战开始（弱化状态）
```

## 平衡性

### 时间分配

```
每个大任务的解谜时间:
- 任务1: 10-15分钟（教学）
- 任务2: 15-20分钟
- 任务3: 20-25分钟
- 任务4-6: 25-30分钟

占游戏总时长: 约15-20%
不会喧宾夺主
```

### 失败处理

**不会Game Over**:
- 解谜失败不会导致战斗失败
- 最多影响奖励
- 提供跳过机制

**鼓励尝试**:
- 失败不扣HP/SP
- 可以无限重试
- 提示系统友好
