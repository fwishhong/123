## 一、苏远行（主角）

### 基本信息
- **全名**：苏远行
- **年龄**：17岁
- **生日**：10月15日（天秤座）
- **身高**：175cm
- **外貌**：清秀、略显瘦弱、黑色短发、深邃的黑眸
- **标志**：手腕上的神秘印记（世界线观测者标记）

### 家庭背景

**父亲**：苏景深
- 大学物理教授
- 研究量子力学
- 在苏远行10岁时与妻子离婚
- 离婚后移居国外，很少联系

**母亲**：林诗雨
- 中学语文教师
- 温柔但忧郁
- 独自抚养苏远行
- 对儿子充满愧疚

**经济状况**：中产偏下，母亲工资勉强维持生活

### 成长经历

**童年（0-10岁）**：
- 天才儿童，智商测试145
- 5岁开始阅读科普书籍
- 父母感情和睦，家庭幸福
- 对世界充满好奇

**转折点（10岁）**：
- 父母激烈争吵后离婚
- 目睹父亲摔门而去的场景
- 第一次体验到"无能为力"的感觉
- 性格开始转变

**少年期（11-16岁）**：
- 成绩依然优秀，但不再突出
- 刻意压抑自己的才能
- 害怕"太优秀会失去一切"
- 逐渐变得孤僻、逃避

**转学前（16岁）**：
- 在原学校遭遇校园霸凌
- 不是身体上的，而是被孤立
- 母亲察觉后决定让他转学
- 苏远行选择逃避而非面对

### 性格特质

**核心特质**：
- **理性至上**：习惯用逻辑分析一切
- **观察敏锐**：能注意到细微的变化
- **情感压抑**：不轻易表露真实情感
- **逃避倾向**：遇到困难第一反应是逃避

**外在表现**：
- 沉默寡言，不主动社交
- 礼貌但疏离
- 喜欢独处
- 眼神常常游离

**内在世界**：
- 极度敏感
- 渴望被理解但害怕被看穿
- 自我保护意识强
- 对他人痛苦有强烈共情

**矛盾之处**：
- 想要逃避，却无法忽视他人的痛苦
- 理性压抑感性，但内心极度感性
- 害怕失去，所以不敢拥有

### 能力与特质

**学术能力**：
- 物理：优秀（受父亲影响）
- 数学：优秀
- 语文：出色（受母亲影响）
- 哲学思辨能力极强

**认知空间形态**：
- **迷雾森林**
- 象征迷茫和迷失
- 到处是岔路，但没有标识
- 浓雾遮蔽视线
- 深处有一座小木屋（心灵避难所）

**特殊能力**：
- **世界线观测者**（γ世界线觉醒）
- 能记住所有世界线的记忆
- 能预见选择导致的结果
- 代价：承受多重世界线的情感重量

### 人际关系

**对宁澈**：
- 最初：羡慕他的阳光和自信
- α世界线：建立深厚兄弟情
- β世界线：因理念不同疏远
- γ世界线：理解并互补

**对姬霜**：
- 最初：被她的"逃避者气息"吸引
- α世界线：保持距离
- β世界线：深爱并依赖
- γ世界线：理解她的创伤

**对温言**：
- 最初：欣赏她的温柔
- 三条世界线：始终想要拯救她
- 象征意义：温言是苏远行"想要拯救但做不到"的自己的投射

**对母亲**：
- 表面：孝顺、听话
- 内心：愧疚、想要保护她
- 不敢表达真实情感，怕让母亲担心

### 成长弧光

**α世界线**：
```
逃避者 → 行动者 → 目睹牺牲 → 质疑选择的意义
核心领悟：牺牲是高尚的，但活着的人要背负更重的痛苦
```

**β世界线**：
```
逃避者 → 选择正义 → 失去一切 → 孤独的虚无
核心领悟：正义的代价可能是失去所有珍贵之物
```

**γ世界线**：
```
逃避者 → 觉醒者 → 协调者 → 承担者
核心领悟：真正的勇气是在知道所有结果后，仍然选择最难的路
```

### 内心台词

**Day 1**（三条世界线共同）：
```
"我一直在逃避。
逃避父亲离开的事实，
逃避同学的孤立，
逃避所有需要我做出选择的时刻。

因为我知道，选择意味着责任，
而责任意味着可能的失败。

我害怕失败。
更害怕失败后，连逃避的地方都没有了。"
```

**α世界线 Day 100**：
```
"宁澈用他的生命告诉我，
有些事值得付出一切。

但他错了。

因为他的牺牲，让我余生都要背负愧疚。
这不是高尚，这是残忍。

如果可以重来...
如果可以..."
```

**β世界线 Day 100**：
```
"我们赢了。
邪恶被摧毁了。

但我站在废墟中，
抱着姬霜冰冷的身体，
突然不知道'胜利'的意义是什么。

没有人分享的胜利，
只是更深的孤独。"
```

**γ世界线 Day 100**：
```
"我看到了所有的可能性。
我知道每一个选择的代价。

所以我不会让任何人牺牲。
不是宁澈，不是姬霜，不是温言。

即使这是最难的路。
即使我要背负三条世界线的记忆。

因为他们教会我：
活着，并承担活着的重量，
才是真正的勇气。"
```

### 象征意义

**量子态的观测者**：
- 薛定谔的猫在被观测前同时是生与死
- 苏远行观测了三条世界线
- 他的选择让世界"塌缩"到唯一的现实

**哲学隐喻**：
- 代表现代人的普遍困境：选择恐惧症
- 在信息爆炸时代，我们看到太多可能性
- 反而失去了做选择的勇气

## 二、宁澈

### 基本信息
- **全名**：宁澈
- **年龄**：17岁
- **生日**：6月21日（夏至，双子座）
- **身高**：182cm
- **外貌**：阳光帅气、金棕色短发、温暖的棕色眼睛、标准运动员身材
- **标志**：右手腕有一道疤痕（实验事故留下）

### 家庭背景

**父亲**：宁远舟
- 神经科学家，BCI技术先驱
- 性格温和、理想主义
- 相信技术能造福人类

**母亲**：苏婉清
- 认知心理学家
- 宁远舟的研究伙伴
- 温柔、有智慧

**家庭氛围**：
- 充满爱和知识
- 父母恩爱，家庭幸福
- 经常讨论科学和哲学
- 宁澈在这样的环境中成长

**悲剧**：
- 宁澈12岁时，父母在实验事故中去世
- 实验目的：验证认知空间理论
- 事故原因：技术不成熟，认知空间崩溃
- 宁澈目睹了整个过程（通过监控）

**监护人**：
- 姑妈宁雨霏（父亲的妹妹）
- 温柔但无法填补父母的空缺
- 给宁澈留下父母的所有研究资料

### 成长经历

**童年（0-12岁）**：
- 完美的家庭
- 聪明、开朗、受人喜爱
- 父母从小培养科学思维
- 10岁开始接触BCI技术基础知识

**创伤事件（12岁）**：
- 父母实验事故那天是他的生日
- 他们想要给他一个"惊喜"（成功的实验）
- 但实验失败了
- 宁澈看着监控中父母的意识消散

**转变期（13-15岁）**：
- 表面上依然阳光，但内心自责
- "如果不是为了我的生日，他们不会急于实验"
- 开始疯狂学习父母的研究
- 立志要完成他们未完成的事业

**现在（17岁）**：
- 东城高中最受欢迎的学生
- 成绩优异、运动全能、性格开朗
- 但没人知道他的痛苦
- 偷偷在大学实验室继续父母的研究

### 性格特质

**外在人格**（面具）：
- 阳光、自信、乐观
- 乐于助人
- 领导力强
- 有感染力的笑容

**内在人格**（真实）：
- 深度自责和愧疚
- 害怕再失去重要的人
- 有英雄情结和救世主心态
- 愿意牺牲自己换取他人幸福

**行为模式**：
- 总是第一个站出来
- 习惯承担所有责任
- 不轻易求助
- 把痛苦藏在笑容背后

**核心信念**：
```
"我没能保护父母，
所以我要保护所有其他人。

即使代价是我自己的生命。"
```

### 秘密与罪恶

**罪恶（5年前）**：
- 父母开始研究认知空间时需要测试对象
- 13岁的宁澈不懂事，邀请了朋友温言参与
- 说这是"很酷的实验"
- 温言信任他，成为早期测试者
- 实验对温言造成了创伤

**隐瞒**：
- 从未告诉温言真相
- 温言不知道是他把她拉入实验的
- 这份罪恶感压在宁澈心上5年

**研究**：
- 偷偷继续父母的BCI研究
- 掌握了"意识献祭"技术
- 可以用一个人的意识修复另一个人
- 但代价是献祭者意识消散

### 能力与特质

**学术能力**：
- 理科全能
- 对神经科学有超出年龄的理解
- 继承了父母的研究天赋

**体能**：
- 篮球队队长
- 短跑健将
- 体力和反应力都很强

**认知空间形态**：
- **永昼之城**
- 永远是白天，阳光刺眼
- 但没有夜晚，无法休息
- 象征他"永远阳光"的伪装
- 城市中心有一座被锁住的塔（藏着他的痛苦）

**战斗风格**：
- 正面刚、光明正大
- 使用"光明领域"压制敌人
- 愿意做人肉盾牌保护他人

### 人际关系

**对苏远行**：
- 第一眼就感觉"这个人需要帮助"
- 想要拉他走出孤独
- α世界线：把他当成最信任的伙伴
- β世界线：因理念不同而失望
- γ世界线：真正平等的友谊

**对姬霜**：
- 尊重但保持距离
- 理解她的冷漠
- α世界线：队友关系
- β世界线：对立
- γ世界线：互补的战友

**对温言**：
- 青梅竹马
- 深深的愧疚感
- 想要保护她但不敢告诉她真相
- 三条世界线都想要救她

### 成长弧光

**α世界线**：
```
伪装的阳光 → 告白罪恶 → 决定献祭 → 光荣的死亡
核心台词："我终于可以赎罪了"
```

**β世界线**：
```
伪装的阳光 → 孤独的战斗 → 失败 → 与温言同死
核心台词："至少，我们在一起"
```

**γ世界线**：
```
伪装的阳光 → 坦白罪恶 → 被宽恕 → 学会活着的勇气
核心台词："原来，活下去比死去更需要勇气"
```

### 内心台词

**α世界线 Day 80（告白）**：
```
"温言，对不起。

五年前，是我骗你参加实验的。
是我害你受伤的。
是我毁了你的。

我知道说对不起已经没有意义。
所以，让我用我的生命来赎罪。

如果我的意识能修复你的认知空间，
那就是我存在的意义。"
```

**α世界线 Day 96（牺牲前）**：
```
"远行，不要哭。

你知道吗，从父母死后，
我每一天都活得很累。

我必须笑，必须强大，必须完美。
因为我怕一旦放松，
就会崩溃。

但现在，我终于可以休息了。

答应我，好好活下去。
替我，替我爸妈，
看看这个世界的未来。"
```

**γ世界线 Day 100**：
```
"我原本打算牺牲的。
就像α世界线和β世界线一样。

但远行阻止了我。
他说：'真正的勇气是活着。'

那一刻我才明白，
我一直想要死，
不是因为高尚，
而是因为逃避。

逃避面对罪恶，
逃避承担责任，
逃避活下去的痛苦。

现在，我选择活着。
并用一生来赎罪，来成长，来爱。"
```

### 象征意义

**光与影的矛盾体**：
- 表面是光（阳光人设）
- 内里是影（罪恶和痛苦）
- 他的成长是学会接受自己的阴影

**英雄主义的反思**：
- α/β世界线：传统英雄，牺牲自己
- γ世界线：新型英雄，活着并承担

### 内心台词

**Day 1（三条世界线）**：
```
"我看着这个世界，
就像隔着一层玻璃。

我能看到人们笑，人们哭，
人们活着。

但我感觉不到。

我知道这不正常。
正常的人应该有情感，有反应。

但我的情感被冻结了。
在某个我不记得的时刻。

我想要找回它。
```

### 成长经历

**童年（0-10岁）**：
- 幸福的家庭
- 聪明、善良

**内在矛盾**：
