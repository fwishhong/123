# MindLink - 认知空间 Web原型

## 🎮 原型说明

这是一个**纯Web技术（HTML/CSS/JavaScript）**实现的游戏原型，用于快速验证核心玩法机制。

**原型范围**: Day 1-15（共15天，45个时间段）

**核心验证点**:
- ✅ 时间管理系统是否有趣
- ✅ 选择系统是否让玩家纠结
- ✅ 属性成长是否有成就感
- ✅ 活动多样性是否足够

---

### 方法1: 直接打开（推荐）

1. 用浏览器打开 `index.html` 文件

## 🎯 游戏玩法

### 目标
在**15天内**通过选择不同的活动来：
1. 提升4种属性（知识、勇气、魅力、战斗力）
2. 与角色建立关系
3. 完成第一个任务

### 核心机制

#### 时间管理
- 每天有**3个时间段**：早晨、下午、夜晚
- 每个时间段只能选择**1个活动**
- 时间一旦推进无法回退（模拟现实的压力）

#### 选择困境
- 不同活动在不同时间段可用
- 有些活动有冷却时间
- 无法完成所有活动，必须取舍
- **这就是核心玩法！**

#### 属性系统
- **知识** 📚: 学习、讲座
- **勇气** ⚔️: 冒险、挑战
- **魅力** ✨: 购物、社交
- **战斗力** ⚡: 训练、探索

#### 关系系统
- **晓**: 青梅竹马，运动型
- **零**: 图书馆管理员，知识型
- 通过特定活动提升好感度

#### 任务系统
- 第一个任务：在Day 15前完成准备工作
- 需要收集3个进度点
- Day 10后解锁调查活动

## 🎮 玩法提示

### 推荐策略

**Day 1-5: 自由探索期**
- 尝试各种活动
- 了解时间段限制
- 开始提升基础属性

**Day 6-10: 专注成长期**
- 选择1-2个主要发展方向
- 注意活动冷却时间
- 平衡社交和属性提升

**Day 11-15: 任务冲刺期**
- 完成任务相关活动
- 确保任务进度达到3
- 最后冲刺提升属性

### 测试要点

玩完15天后，思考：

1. **时间压力**: 你是否感到时间不够用？（理想：是）
2. **选择困难**: 你是否纠结选哪个活动？（理想：是）
3. **成就感**: 看到属性升级是否有满足感？（理想：是）
4. **重玩欲望**: 你想重玩尝试不同路线吗？（理想：是）

## 🛠️ 技术细节

### 文件结构

```
prototype/web/
├── index.html          # 主HTML文件
├── css/
│   └── style.css       # 样式表
├── js/
│   └── game.js         # 游戏逻辑
└── README.md           # 本文件
```

### 核心实现

**时间系统**:
```javascript
currentDay: 1-15
currentTimeslot: 'morning' | 'afternoon' | 'night'
advanceTime() // 推进时间
```

**属性系统**:
```javascript
attributes: {
    knowledge: { level, exp, expToNext },
    courage: { level, exp, expToNext },
    ...
}
addAttributeExp(attr, amount) // 添加经验
```

**事件系统**:
```javascript
eventsData: [...] // 事件列表
conditions: { timeslots, minDay, minProgress, ... } // 触发条件
effects: { knowledge, relationships, ... } // 效果
```

## ⚡ 快速修改指南

### 调整天数
```javascript
// game.js 第7行
this.maxDay = 15; // 改为你想要的天数
```

### 添加新活动
```javascript
// game.js 第70行
eventsData.push({
    id: 'new_activity',
    name: '新活动',
    description: '描述',
    icon: '🆕',
    category: 'custom',
    conditions: { timeslots: ['afternoon'] },
    effects: { knowledge: 20 },
    repeatable: true
});
```

### 调整属性升级速度
```javascript
// game.js 第37行
attr.expToNext = Math.floor(attr.expToNext * 1.5); // 调整这个倍率
```
