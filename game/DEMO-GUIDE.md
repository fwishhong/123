## 🎯 游戏玩法

### 目标
在Day 15前做好准备，完成第一次拯救任务

### 建议流程

#### Day 1-3: 开场
```
Day 1 早晨: 自动触发觉醒剧情
Day 1 下午: 自动触发遇见晓
       → 选择"告诉她"可获得+2好感度
Day 1 夜晚: 自由活动

Day 2 下午: 自动触发认知崩溃事件

Day 3 夜晚: 自动触发教程战斗
       → 获得+2战斗力
```

#### Day 4-7: 遇见伙伴
```
Day 5 夜晚: 遇见零（黑客）
Day 7 下午: 遇见美月（学生会长）

建议活动:
- 战斗训练（提升战斗力）
- 和晓一起（提升好感度）
- 打工（赚钱备用）
```

#### Day 8-14: 准备阶段
```
Day 10 夜晚: 任务简报
       → 获得恢复药剂和能量饮料

Day 12 (如果晓好感度>=3): 晓的训练剧情
       → 选择"陪她继续训练"获得+3好感度

Day 14 夜晚: 决战前夜
       → 与晓的约定

建议活动:
- 重点提升战斗力到Lv2+
- 保持与晓的互动
- 确保有足够金钱
```

#### Day 15: 决战
```
自动触发任务剧情
→ 完成后获得大量奖励
```

## 📝 开发者笔记

### 技术实现
- 纯HTML + CSS + JavaScript
- 无框架依赖
- 单文件实现
- 约1300行代码

### 数据结构
```javascript
GameData.dialogues = {
    event_id: {
        id, location, day, period,
        lines: [ { speaker, text, choices } ],
        branches: { branch_name: [ lines ] },
        rewards: { flags, combat, relationship, items }
    }
}
```

### 可扩展性
- 添加新剧情: 在dialogues中添加事件
- 添加新活动: 在activities数组中添加
- 添加新角色: 扩展relationships对象
- 添加新分支: 在branches中定义
